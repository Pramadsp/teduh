# Release Notes - Versi 1.0.7

**Tanggal Rilis:** 2 Oktober 2026  
**Build Version:** `1.0.7+22`

---

## 🛠️ Perbaikan Utama: Quick Setting App Lock & Transfer Navigasi (v1.0.7)
- **Perbaikan Quick Setting Android (`UserActivityDetector`):**
  - Mengubah kriteria penguncian aplikasi agar **HANYA aktif saat status `AppLifecycleState.paused`** (yaitu saat aplikasi benar-benar di-minimize ke home / berpindah ke aplikasi lain).
  - Menggeser bilah **Quick Setting / Panel Notifikasi Android (`inactive`)** kini **TIDAK AKAN memicu penguncian PIN/Biometrik lagi**.
- **Perbaikan Alur Transfer & Otorisasi PIN/Biometrik (`TransferModal` & `PinVerificationModal`):**
  - Setelah biometrik / PIN terverifikasi dan transfer atomic sukses terkirim, modal transfer otomatis ditutup dengan mulus dan **langsung mengalihkan tampilan ke Beranda (Dashboard)** via `MainScreen.switchTab(context, 0)`.
  - Mencegah penutupan rute berantai saat tombol silang/batal ditekan sehingga **100% terhindar dari layar blank hitam**.
- **Update Versi Aplikasi:** Subtitle pada menu Pengaturan ter-update menjadi **`v1.0.7 (Teduh Official Release)`**.
