# Release Notes - Versi 1.0.6

**Tanggal Rilis:** 2 Oktober 2026  
**Build Version:** `1.0.6+21`

---

## 🚀 Perbaikan Alur Navigasi Transfer & Biometrik (v1.0.6)
- **Otomatisasi Redirect ke Beranda (`MainScreen.switchTab(context, 0)`):**
  - Setelah verifikasi PIN / pindaian biometrik sidik jari sukses dan transaksi transfer terkirim, modal transfer otomatis ditutup dengan mulus.
  - Tampilan aplikasi **langsung dialihkan secara otomatis ke Beranda (Dashboard)** untuk menampilkan saldo grup yang ter-update secara real-time.
  - Menampilkan `SnackBar` floating sukses: *"Transfer saldo Rp X ke [Nama Anggota] berhasil!"*.
- **Pencegahan Layar Blank Hitam:**
  - Ditambahkan tombol silang pembatalan (`Icons.close_rounded`) pada modal PIN.
  - Pengecekan aman `Navigator.canPop()` mencegah penutupan rute berantai yang dapat memicu layar hitam OS.
- **Update Versi Aplikasi:** Subtitle pada menu Pengaturan ter-update menjadi **`v1.0.6 (Teduh Official Release)`**.
