# Release Notes - Versi 0.6.0

**Tanggal Rilis:** 2 Oktober 2026  
**Build Version:** `0.6.0+7`

---

## 📊 Fitur Baru: Ekspor PDF & Excel (Fase 6 Selesai)
- **Ekspor Dokumen PDF:**
  - Menghasilkan rekap laporan keuangan ber-halaman rapi dalam format PDF.
  - Berisi identitas grup keluarga, rentang periode terpilih (WIB), kartu ringkasan (Pemasukan, Pengeluaran, Saldo), tabel rincian pengeluaran per kategori, dan tabel daftar transaksi lengkap dengan penomoran halaman otomatis (`pdf` + `printing`).
- **Ekspor Lembar Kerja Excel (.xlsx):**
  - **Sheet 1 (Ringkasan):** Berisi total pemasukan, total pengeluaran, saldo netto, dan tabel rincian per kategori.
  - **Sheet 2 (Daftar Transaksi):** Berisi rincian lengkap transaksi dengan nominal bertipe **Integer** agar dapat di-SUM/dikalkulasi secara langsung di Microsoft Excel atau Google Sheets (`excel`).
- **Integrasi Langsung:**
  - Terhubung dengan `open_filex` (buka file langsung) dan `share_plus` (bagikan file ke WhatsApp, Email, Google Drive, dll).

---

## 📝 Fitur Baru: Field "Nama Transaksi" (Title)
- **Nama / Judul Transaksi Spesifik:**
  - Menambahkan field wajib **Nama Transaksi** pada form Tambah/Edit Transaksi (contoh: *"Beli Kue"*, *"Gaji Bulanan"*, *"Beli Bensin"*).
  - Field Catatan (opsional) tetap dipertahankan untuk deskripsi tambahan detail.
  - Nama transaksi kini ditampilkan sebagai **judul utama (teks bold)** di layar Beranda, Daftar Transaksi, Laporan, serta file ekspor PDF dan Excel.

## 🎨 Perbaikan UI & Polishing Theme
- **Perbaikan Input Field Form Transaksi:** Field "Nominal", "Kategori", dan "Catatan" kini menggunakan background Pasir (`#F1EBDD`) yang seragam dengan container *Tanggal Transaksi*, dan teks Tinta (`#2F3A32`) bold.
- **Warna Tab Tidak Aktif:** Seluruh tab pilihan (Harian/Mingguan/Bulanan di Laporan, Buat/Gabung Grup di Household, Pemasukan/Pengeluaran di Transaksi) dipastikan menggunakan warna font `AppColors.ink` bold agar kontras dan sangat jelas terbaca.
- **Ketersediaan DatePicker Theme:** Penyesuaian skema warna dialog tanggal agar kontras dan terbaca terang di atas background Krem.
- **Dinamis Transaksi Terakhir:** Judul header seksi di Beranda kini menyesuaikan jumlah transaksi yang tampil secara dinamis.
- **Fix Auto Profile Creation:** Menambahkan penanganan otomatis pembuat dokumen UserProfile Firestore di background jika pengguna mendaftar/login pertama kali.
