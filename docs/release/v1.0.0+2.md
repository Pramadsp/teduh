# Release Notes - Teduh v1.0.0+2

**Versi Aplikasi:** `1.0.0+2`  
**Tanggal Rilis:** 1 Oktober 2026  
**Status:** CRUD Transaksi Selesai (Fase 2 Selesai)

---

## 📝 Ringkasan Rilis
Rilis `v1.0.0+2` mengimplementasikan fitur lengkap pencatatan transaksi (CRUD) beserta manajemen state berbasis Riverpod dan pembatasan input nominal IDR otomatis.

---

## ✨ Perubahan & Fitur Baru (Fase 2)

### 1. State Management (Riverpod)
- Menambahkan `transaction_providers.dart` untuk mengelola state `categoriesProvider` dan `transactionsProvider`.
- Integrasi `ProviderScope` di `main.dart`.

### 2. Form Tambah & Ubah Transaksi (`TransactionFormModal`)
- Modal bottom sheet responsif dengan keyboard avoidance.
- **Segmented Control Toggle:** Pilihan tipe transaksi (Pengeluaran / Pemasukan).
- **Nominal Formatter:** `CurrencyInputFormatter` untuk format ribuan otomatis (hanya menerima angka > 0).
- **Category Picker:** Dropdown kategori terfilter otomatis berdasarkan tipe transaksi aktif.
- **Date Picker:** Pemilih tanggal transaksi lokal.
- **Form Validation:** Validasi nominal wajib > 0 dan kategori wajib dipilih.

### 3. Layar Daftar Transaksi (`TransactionListScreen`)
- Dikelompokkan rapi per header tanggal (format lengkap Bahasa Indonesia).
- Visual indikator yang jelas & aksesibel (Warna hijau/merah + tanda `+`/`-` + ikon panah naik/turun).
- Menampilkan nama kategori, nominal, pencatat, dan catatan opsional.
- **Action Edit:** Tap pada item transaksi untuk membuka form ubah transaksi.
- **Action Hapus & Undo:** Long press pada item transaksi menampilkan dialog konfirmasi hapus, disertai fitur Undo melalui SnackBar.
- **Floating Action Button (FAB):** Tombol tambah cepat berterakota di pojok kanan bawah.
