# Release Notes - Versi 1.0.3

**Tanggal Rilis:** 2 Oktober 2026  
**Build Version:** `1.0.3+18`

---

## 💸 Fitur Utama: Dropdown Pemilihan Penerima Transfer & Real-Time Sync Fix (v1.0.3)
- **Pilihan Penerima Transfer Saldo (`TransferModal`):**
  - Dropdown `Penerima Transfer Saldo` kini **selalu ditampilkan secara aktif** di bagian atas form transfer saldo.
  - Pengguna (Pengirim) dapat secara fleksibel memilih anggota penerima dari daftar anggota grup (`${displayName} (${email})`).
  - Kartu indikator transfer (*DARI ➔ KE*) secara otomatis ter-update secara visual saat penerima baru dipilih.
- **Koneksi Dinamis Real-Time Firestore:**
  - Mengubah provider `transactionRepositoryProvider` & `categoryRepositoryProvider` agar terhubung langsung ke Firestore (`activeHouseholdIdProvider`).
  - Transaksi baru dan update saldo kini langsung ter-push real-time ke seluruh HP anggota grup.
- **Update Versi Aplikasi:** Subtitle pada menu Pengaturan ter-update menjadi **`v1.0.3 (Teduh Official Release)`**.
