# Release Notes - Teduh v0.1.0

**Versi Aplikasi:** `0.1.0+1`  
**Tanggal Rilis:** 1 Oktober 2026  
**Status:** Inisialisasi & Fondasi (Fase 0 & Fase 1 Selesai)

---

## 📝 Ringkasan Rilis
Rilis perdana ini meletakkan fondasi arsitektur, identitas visual, tata letak navigasi, serta infrastruktur data awal untuk aplikasi **Teduh** (Aplikasi Pencatat Keuangan Keluarga privat).

---

## ✨ Perubahan & Fitur Baru (Fase 0 & 1)

### 1. Inisialisasi & Setup Proyek
- **Package Name / Application ID:** `com.nayanara.teduh`
- **Label Aplikasi:** `Teduh`
- **Integrasi Version Control:** Inisialisasi repository Git terisolasi dan tersambung ke `https://github.com/Pramadsp/teduh.git` (branch `main`).
- **Keamanan Secret:** Konfigurasi `.gitignore` untuk melindungi file sensitif (`key.properties`, `*.jks`, `*.keystore`, `google-services.json`, `.fvm/`).
- **Manajemen Package:** Penambahan pustaka ekosistem Flutter (`flutter_riverpod`, `go_router`, `intl`, `fl_chart`, `pdf`, `printing`, `excel`, `path_provider`, `share_plus`, `open_filex`).

### 2. Identitas Visual & Tema (Material 3)
- **Desain & Warna:** Implementasi `AppColors` & `AppTheme` Material 3 bernuansa tenang & hangat (Sage `#6B8F71`, Krem `#FAF6EE`, Pasir `#F1EBDD`, Terakota `#C8704A`, Tinta `#2F3A32`, Pemasukan `#4F8A5B`, Pengeluaran `#C0583F`).
- **Dukungan Dark Mode:** Implementasi tema gelap (`darkBackground` `#1E2420`, `darkSurface` `#28302A`, `darkText` `#E8EDE6`).

### 3. Navigasi & Tata Letak Utama
- **Bottom Navigation ShellRoute:** Menggunakan `go_router` dan `NavigationBar` Material 3 untuk 4 tab utama:
  1. 🏠 **Beranda** (`/dashboard`)
  2. 🧾 **Transaksi** (`/transactions`)
  3. 📊 **Laporan** (`/reports`)
  4. ⚙️ **Pengaturan** (`/settings`)

### 4. Formatters & Lokalisasi (IDR)
- Format mata uang Rupiah integer: `CurrencyUtils.formatRupiah(int)` (contoh: `Rp 1.250.000`).
- Helper tanggal Indonesia `DateUtilsId` dengan format lokal `id_ID`.

### 5. Arsitektur Data & Model
- **Model Data:** `Transaction` (nominal `int` IDR) dan `Category` beserta fungsi serialisasi `toMap` / `fromMap`.
- **Interface & In-Memory Repository:** `TransactionRepository` & `CategoryRepository` untuk pengembangan awal.
- **Default Seed Categories:** 9 Kategori Pengeluaran (Makan & Minum, Belanja Rumah Tangga, Transportasi, Tagihan & Utilitas, Kesehatan, Pendidikan, Hiburan, Sedekah & Donasi, Lainnya) dan 4 Kategori Pemasukan (Gaji, Bonus, Usaha, Lainnya).
