# Release Notes - Teduh v0.5.0

**Versi Aplikasi:** `0.5.0+5`  
**Tanggal Rilis:** 1 Oktober 2026  
**Status:** Firebase, Login, Household, dan Sinkronisasi Selesai (Fase 5 Selesai)

---

## 📝 Ringkasan Rilis
Rilis `v0.5.0` menandai migrasi utama aplikasi **Teduh** dari penyimpanan lokal *in-memory* ke **Firebase Cloud Infrastructure**. Aplikasi kini mendukung Autentikasi (Email & Password), Pembuatan & Penggabungan Grup Keluarga (*Household* 2 orang dengan kode undangan 6 karakter), serta sinkronisasi data transaksi dan kategori secara *real-time online & offline persistence*.

---

## ✨ Perubahan & Fitur Baru (Fase 5)

### 1. Inisialisasi Firebase & Offline Persistence
- Penambahan package `firebase_core`, `firebase_auth`, dan `cloud_firestore` di `pubspec.yaml`.
- Konfigurasi `Firebase.initializeApp()` dan pengaktifan *Firestore Offline Persistence* pada `main.dart` agar data dapat dicatat tanpa koneksi internet.

### 2. Autentikasi (`LoginScreen` & `AuthService`)
- Layar Masuk (Login) dan Daftar (Register) Email & Password.
- Penanganan error komprehensif dalam Bahasa Indonesia (misal: kata sandi salah, email sudah terdaftar, dsb).
- Tombol *Keluar Akun* pada menu Pengaturan.

### 3. Alur Grup Keluarga Privat / Household 2 Orang (`HouseholdSetupScreen`)
- **Buat Grup Baru:** Pengguna pertama mendaftar dan membuat grup keluarga, menghasilkan kode unik 6 karakter (misal: `A8K9X2`).
- **Gabung Kode:** Pengguna kedua mendaftar dan memasukkan kode undangan (menggunakan `FieldValue.arrayUnion` untuk menambahkan UID ke `memberIds`).
- **Seed Kategori Otomatis:** Saat grup dibuat, 13 kategori default (9 Pengeluaran & 4 Pemasukan) langsung di-seed secara otomatis ke Firestore Household.

### 4. Real-Time & Offline Firestore Repositories
- **`FirestoreTransactionRepository` & `FirestoreCategoryRepository`:** Menggunakan `snapshots()` stream untuk mendengarkan perubahan data transaksi & kategori secara *real-time*.
- **`AuthGate` Widget:** Mengontrol akses routing (Login ➔ Setup Household ➔ Main Dashboard dengan Provider Overrides per Household).

## 📋 Langkah Manual User yang Diperlukan ([MANUAL USER] M2)
Pengguna perlu menyalin Firestore Security Rules berikut ke **Firebase Console > Cloud Firestore > Rules**:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    function signedIn() {
      return request.auth != null;
    }

    function isMember(hid) {
      return signedIn() &&
        request.auth.uid in get(/databases/$(database)/documents/households/$(hid)).data.memberIds;
    }

    match /users/{uid} {
      allow read, write: if signedIn() && request.auth.uid == uid;
    }

    match /invites/{code} {
      allow get: if signedIn();
      allow create: if signedIn();
      allow list, update, delete: if false;
    }

    match /households/{hid} {
      allow create: if signedIn() && request.auth.uid in request.resource.data.memberIds;
      allow read: if isMember(hid);
      allow update: if isMember(hid) || (
        signedIn() &&
        request.auth.uid in request.resource.data.memberIds &&
        request.resource.data.memberIds.size() <= 2 &&
        request.resource.data.memberIds.hasAll(resource.data.memberIds)
      );
      allow delete: if false;

      match /{document=**} {
        allow read, write: if isMember(hid);
      }
    }
  }
}
```
