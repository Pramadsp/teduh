## 🛠️ Perbaikan Utama: Dropdown Assertion & Equatable Fix (v1.0.4)
- **Perbaikan Dropdown Pilihan Penerima Transfer (`TransferModal`):**
  - Mengubah generic value `DropdownButtonFormField` dari `UserProfile` menjadi `String` (`uid`) yang 100% aman dan presisi dari perbandingan instance memori.
  - Menambahkan `operator ==` dan `hashCode` pada `UserProfile` model agar perbandingan object penerima di Flutter 100% konsisten tanpa melempar `AssertionError`.
  - Dropdown pilihan penerima kini dapat dibuka dan dipilih dengan sangat lancar tanpa layar merah.
- **Update Versi Aplikasi:** Subtitle pada menu Pengaturan ter-update menjadi **`v1.0.4 (Teduh Official Release)`**.
