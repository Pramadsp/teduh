# Release Notes - Versi 0.7.0

**Tanggal Rilis:** 2 Oktober 2026  
**Build Version:** `0.7.0+8`

---

## 🌟 Fitur Baru: Penyempurnaan & Visual Polishing (Fase 7 Selesai)
- **Search & Filter Bar Real-Time (`TransactionListScreen`):**
  - Search Bar di atas daftar transaksi untuk menyaring transaksi berdasarkan Nama Transaksi (`title`), Catatan (`note`), atau Kategori (`categoryName`).
  - Dilengkapi tombol clear query dan tampilan Empty State khusus jika transaksi yang dicari tidak ditemukan.
- **Icon Export & AppBar Polishing (`ReportScreen`):**
  - Mengubah icon ekspor laporan menjadi `Icons.file_download_outlined` beraksen `AppColors.sageDark` yang intuitif dan menyatu dengan background Krem.
- **Custom App Launcher Icon (`flutter_launcher_icons`):**
  - Menghasilkan App Icon resmi Android khas Teduh (siluet pohon rindang dengan latar Sage Dark `#4A6B50` & Krem `#FAF6EE`).
- **Animasi Transisi Smooth Antar Tab (`app_router.dart`):**
  - Menambahkan animasi `FadeTransition` pada ShellRoute bottom navigation untuk transisi antar-tab yang sangat halus tanpa kedipan kasar (*blip-blip*).

---

## 👤 Fitur Profil & Manajemen Kategori
- **Fitur Edit Nama Pengguna (`ProfileScreen`):**
  - Ditambahkan tombol pensil untuk memperbarui `displayName` di Firebase Auth dan Firestore real-time. Email tetap dikunci (*read-only*).
- **Perbaikan Kontras Tab & Field Kategori (`CategoryListScreen`):**
  - Tab tidak aktif kini menggunakan warna teks `AppColors.ink` bold di atas background Pasir (`#F1EBDD`).
  - Field input "Nama Kategori" diselaraskan menggunakan background Pasir `#F1EBDD`.

---

## 🛡️ Anti-Spam & Loading States
- **Loading State & Button Disabled:**
  - Menambahkan state `isSubmitting` dan `CircularProgressIndicator` ukuran 18 (`strokeWidth: 2`) pada seluruh tombol Simpan / Perbarui / Buat di modal transaksi, dialog profil, dialog kategori, dan setup household untuk mencegah duplicate hit / spam click dari pengguna.
